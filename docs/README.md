# Master Documentation Set

The documentation set is the source of authority for Kingdom Executor OS. Each volume answers a different implementation question.

| Volume | Purpose | Status |
| --- | --- | --- |
| I — Constitution | Why the system exists and how decisions are governed | Baseline v1.0 |
| II — PRD | What to build and how acceptance is measured | Planned |
| III — System Architecture | How approved features are implemented | Planned |
| IV — Engineering Handbook | How engineering work is performed | Planned |
| V — Brand Manuals | How brand modules preserve identity and operations | Planned |
| VI — AI Executive Council | How AI agents are defined, bounded, and escalated | Planned |
| VII — Workflow Library | How repeatable operations run | Planned |
| VIII — Deployment & Operations | How production systems are released and operated | Planned |

## Build Discipline

Kingdom Executor OS uses documentation-first development:

1. Finish and commit the governing document.
2. Scaffold only what the approved document requires.
3. Add tests and deployment paths for approved features.
4. Repeat in small, working increments.
